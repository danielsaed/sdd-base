# Backlog — what's next, across areas

> **Answers:** in which order the next specs go, across areas. One line per spec, by
> `<area>/<slug>` (never by number), linking to its area's **Pending** section, where the
> detail lives. **Update when:** a spec opens (delete its line), the order changes or an
> area's pending item becomes next. Reordering renumbers nothing.
> Limit: 80 lines. `[D]` = waits for a user decision · `[B]` = blocked.
